# AI Học Nhìn Ảnh — Mở hộp đen xem máy học

Hệ thống demo học máy trực quan cho Tiết 9 Lớp 7 — Đạo đức dữ liệu huấn luyện AI (mã 7.C4.1, Bài 10).

- Luồng 4 chặng: Ảnh vào → AI nhìn (thành 2 con số: độ sáng, độ tương phản) → Hộp đen (bản đồ chấm + quy tắc 3 chấm gần nhất) → Đầu ra (AI đoán + vì sao đúng/sai).
- Hộp đen 3D mở ra được: bên trong không có phép thuật, chỉ có bản đồ dữ liệu và 1 quy tắc so sánh.
- Demo: ảnh đủ sáng AI đoán đúng 98%; ảnh thiếu sáng AI đoán sai (nhận nhầm thành Bàn ghế); thêm 3 ảnh tối vào thì ảnh tối lại đúng 96% — đúng bài học "dữ liệu thiếu đa dạng".
- Chạy hoàn toàn trong trình duyệt, không cần tài khoản, không tải dữ liệu lên mạng. Ảnh mẫu là hình minh họa 3D.
- Mở bằng Chrome (cần https để dùng webcam — trang GitHub Pages này đã là https).

Mở tại: https://ngochung3789-boop.github.io/bai10AI/
